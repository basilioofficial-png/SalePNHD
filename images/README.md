# Папка для фотографий

Сейчас на странице вместо фото — заглушки (плашки с подписью вроде «ФОТО 02 — футболки»). Это сделано специально: чтобы страницу можно было выкатить уже сейчас, а фото добавить позже без пересборки сайта.

## Как заменить заглушку на реальное фото

1. Положите файл сюда, в `images/` (лучше в `.webp`, размеры — см. таблицу ниже).
2. Откройте `index.html`, найдите нужный `<div class="ph-slot">…</div>` (по подписи, например «ФОТО 02 — футболки»).
3. Замените его на `<img src="images/tshirts.webp" alt="Футболки Studio PNHD" loading="lazy">` (для фото в первом экране `loading="lazy"` не ставьте — оно должно грузиться сразу).
4. Сохраните, закоммитьте — Vercel пересоберёт сайт автоматически.
