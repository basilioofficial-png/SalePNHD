# Studio PNHD — лендинг распродажи трикотажа

Одностраничный промолендинг для офлайн-распродажи трикотажа Studio PNHD, 19–20 сентября 2026. Собран как обычный статический сайт — чистые HTML/CSS/JS, без сборщиков и фреймворков, чтобы его было легко редактировать и быстро деплоить.

## Откуда это взялось

Исходник был сделан в Claude Design и выгружен в служебном формате `.dc.html` — он открывается только внутри рантайма Claude Design (React, специальные теги `<x-dc>`, `sc-if` и т.д.) и не может быть просто загружен на хостинг. Здесь тот же дизайн, тексты и структура блоков пересобраны в обычный HTML/CSS/JS, который открывается в любом браузере и деплоится на Vercel как статический сайт.

Исходные материалы (ТЗ и чек-лист ассетов) сохранены в `docs/` — на будущее, если понадобится свериться с изначальным заданием.

## Структура проекта

```
index.html          — вся страница целиком (один файл, блоки идут по порядку ТЗ)
css/style.css        — стили: цвета, шрифты, сетка, все компоненты
js/main.js           — вся интерактивность (меню, FAQ, форма, аналитика, .ics, режим "мероприятие завершено")
assets/              — логотип и графические знаки бренда (SVG)
fonts/               — шрифты TT Bluescreens и Heading Pro (см. "Шрифты и лицензии" ниже)
images/              — сюда кладутся реальные фото (см. images/README.md — что именно нужно и в каком размере)
docs/                — исходное ТЗ и чек-лист ассетов от Claude Design (справочно)
```

Никакой сборки не требуется — это не React/Vue-проект, а обычные файлы. Открыть `index.html` в браузере можно и напрямую, но для локальной разработки удобнее поднять локальный сервер (см. ниже).

## Как посмотреть локально

```bash
npx serve .
# или
python3 -m http.server 8000
```

и открыть `http://localhost:3000` (или `:8000`).

## Как дорабатывать дальше

Просто редактируйте `index.html`, `css/style.css`, `js/main.js` — это обычный текст. Дальше:

```bash
git add -A
git commit -m "описание изменения"
git push
```

Если репозиторий подключён к Vercel (см. ниже), после `push` сайт обновится автоматически за 20–40 секунд.

## Деплой на GitHub и Vercel

**GitHub.** Код уже запушен в этот репозиторий, в ветку `claude/landing-deploy-github-vercel-9q0fi6`.

**Vercel.** У меня нет доступа к вашему аккаунту Vercel, поэтому подключить репозиторий нужно один раз вручную (2 минуты):

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New → Project**.
3. Выберите репозиторий `basilioofficial-png/SalePNHD`.
4. Framework Preset — оставьте **Other** (это статический сайт, сборка не нужна). Root Directory — оставьте пустым (`.`).
5. Нажмите **Deploy**.

После этого Vercel сам подхватывает каждый `push` в репозиторий: пуш в основную ветку обновляет продакшен-адрес, пуш в любую другую ветку или PR — создаёт отдельную предпросмотровую ссылку. Свой домен (например `studio.pnhd.ru`) можно будет подключить в настройках проекта на Vercel в любой момент.

## Что нужно донастроить перед публикацией (реальные данные вместо плейсхолдеров)

Все места, где сейчас стоит "Плейсхолдер: …", видно прямо на странице — их специально оставили заметными, чтобы не публиковать непроверенные данные. Нужно:

- **Ссылка на Яндекс Карты** — сейчас кнопки "Построить маршрут" ведут на `#place` (якорь на блок адреса). Замените `href="#place"` на реальную ссылку на карточку в Яндекс Картах у всех элементов с классом `js-route-link`.
- **Прайс и скидочная сетка** — блок "Больше вещей — выгоднее цена" (`#discounts` в `index.html`) сейчас с плейсхолдерами `[N]`, `[X%]`.
- **Размеры/цвета/цены на карточках товаров** — блок "Выбирайте свою базу" (`#assortment`).
- **Подпись "Вход свободный"** — сейчас закомментирована как плейсхолдер в блоке `#place`, включить после подтверждения.
- **Контакты** — телефон, Telegram, e-mail в футере (сейчас `tel:+70000000000` и заглушки).
- **Реквизиты и политика обработки данных** — футер и чекбокс согласия в форме.
- **Фото** — см. `images/README.md`, там таблица с размерами и назначением каждого фото, включая OG-картинку для превью в соцсетях.
- **Форма заявки** — сейчас работает только во фронтенде (валидация + экран "Заявка отправлена"), но никуда не отправляется. Нужно подключить приём данных: проще всего — serverless-функция на Vercel (`api/lead.js`), которая шлёт заявку в вашу CRM/почту/Telegram, либо сторонний сервис форм (Getform, Formspree). UTM-метки и источник трафика уже собираются в скрытые поля формы (`utm_source`, `utm_medium` и т.д.) — их нужно просто передать вместе с остальными данными.
- **Аналитика** — в `<head>` `index.html` есть комментарии `TODO: Яндекс.Метрика` / `TODO: GA4` с местом для счётчиков. Все события (`sale_route_click`, `sale_form_submit` и т.д. — полный список из ТЗ) уже настроены в `js/main.js` и пушатся в `dataLayer`, как только счётчики подключите — они начнут долетать.

## Режим «мероприятие завершено»

После 20 сентября 2026, 20:00 (по Москве) страница сама переключается: даты пропадают из активного оффера, наверху появляется баннер, а основной CTA меняется на «Заказать трикотаж и нанесение». Дата зашита в `js/main.js`, константа `SALE_END_ISO` — если событие перенесут, поменяйте только её.

## Шрифты и лицензии

В `fonts/` лежат файлы **TT Bluescreens** (typetype.ru) и **Heading Pro** (Fontfabric) — оба коммерческие шрифты. Они попали сюда из вашей исходной дизайн-системы (Claude Design), но я не проверял, распространяется ли лицензия на веб-хостинг конкретно этих файлов на публичном сайте. Перед тем как открывать сайт для реального трафика, стоит свериться с условиями лицензии на этих шрифтов (в частности — покрывает ли она `@font-face` на домене studio.pnhd.ru). Roboto Condensed (текстовый шрифт) подключается с Google Fonts и лицензионных вопросов не создаёт.
